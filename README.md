# Portal Académico — Backend

Equipo actual: Josué Delgado Corrales y Sebastián Cordero Quesada.

Repositorio local preparado para el backend del proyecto de IF-6100. El PC1 corresponde a la fase de Inicio y no contenía un backend ejecutable. Los 48 archivos originales están conservados en el repositorio de documentación y su tag `pc1`.

Para el PC2 está pendiente configurar Spring Boot 3 con Java 21 y Maven, PostgreSQL y una migración inicial con Liquibase; exponer un endpoint de prueba y comprobar la integración con el frontend. También quedan pendientes los lineamientos y la guía de ambiente.

Este repositorio por ahora contiene únicamente la preparación inicial; no es una aplicación ejecutable ni una entrega terminada. El destino solicitado es `IF-6100-2026`, pendiente de verificar permisos y publicar.
