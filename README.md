# Portal Académico — Backend

Equipo actual: Josué Delgado Corrales y Sebastián Cordero Quesada.

Repositorio del backend del proyecto de IF-6100 en la organización [IF-6100-2026](https://github.com/IF-6100-2026). El PC1 corresponde a la fase de Inicio y no contenía un backend ejecutable. Los 48 archivos originales están conservados en [documentación](https://github.com/IF-6100-2026/portal-academico-documentacion) y su [tag `pc1`](https://github.com/IF-6100-2026/portal-academico-documentacion/tree/pc1).

Para el PC2 está pendiente configurar Spring Boot 3 con Java 21 y Maven, PostgreSQL y una migración inicial con Liquibase; exponer un endpoint de prueba y comprobar la integración con el frontend. También quedan pendientes los lineamientos y la guía de ambiente.

Este repositorio por ahora contiene únicamente README y `.gitignore` de preparación inicial; no es una aplicación ejecutable ni una entrega terminada.
